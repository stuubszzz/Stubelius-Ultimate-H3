STUBELIUS ULTIMATE H3 - install and update
==========================================
Workflow: Stubelius_Ultimate_H3.json
Nodes:    https://github.com/stuubszzz/Stubelius-Ultimate-H3


1. INSTALL THE NODES (once)
---------------------------
Option A - ComfyUI Manager:
  Manager > Install via Git URL > paste
      https://github.com/stuubszzz/Stubelius-Ultimate-H3
  then restart ComfyUI. (Some Manager security levels block Git URLs - then use option B.)

Option B - git:
  Open a terminal in ComfyUI/custom_nodes and run
      git clone https://github.com/stuubszzz/Stubelius-Ultimate-H3
  Windows portable: install its requirement with ComfyUI's own Python, from the
  ComfyUI_windows_portable folder:
      python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\Stubelius-Ultimate-H3\requirements.txt
  Restart ComfyUI.


2. GET THE NEWEST VERSION (any time)
------------------------------------
Manager > Update All - or run this in ComfyUI/custom_nodes/Stubelius-Ultimate-H3:
    git pull
then restart ComfyUI. The newest workflow is always in ComfyUI's template browser
(Workflow > Browse Templates > Stubelius-Ultimate-H3) and at the same download link.


3. OTHER NODE PACKS
-------------------
Easiest: install this pack first, load the workflow, then Manager > Install Missing Custom Nodes.

5. FIRST RUN
------------
Load Stubelius_Ultimate_H3.json, check that the Models node shows your files, press Queue.
The example is a 12.5 s text-to-video shot of a glassblower - replace it with your own in the
Director. The HOW TO USE note inside the workflow explains every node.

Developed on an RTX 5090 (32 GB). With less VRAM, turn on the Models node's low-VRAM options
or use GGUF models.
